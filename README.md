# csv-row-cleaner

Small helper that drops empty rows from a CSV export.

## Bug

`csv_cleaner.py` still keeps blank lines. Empty rows should be removed. A row that contains only spaces counts as empty.

## Run

```
python3 csv_cleaner.py sample.csv
```
